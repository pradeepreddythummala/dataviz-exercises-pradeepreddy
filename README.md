# Week 09 – World Happiness Dashboard

## Overview
This Streamlit dashboard visualizes the World Happiness Report 2023 dataset. It allows users to explore happiness scores across different regions using interactive filters and charts.

## Features
- Region filter
- Top N countries filter
- KPI cards
- Happiness ranking bar chart
- GDP vs Happiness scatter plot
- Factor breakdown chart

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Dataset
- World Happiness Report 2023

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
